# Module 9: Nav & routing

See [`README.md`](./README.md) for full background/goal. Depends on:
[`table-management-ui.md`](./table-management-ui.md) (module 5),
[`zone-floorplan-ui.md`](./zone-floorplan-ui.md) (module 6),
[`reservations-ui.md`](./reservations-ui.md) (module 7).

## What

Small wiring module — make the new/updated pages reachable from the
sidebar, and let route codegen pick up the new route files.

## Files

- `apps/restaurant-ui/src/components/layout/AppSidebar.tsx`: add
  `{ to: '/tables', label: 'Tables', icon: Armchair }` to the
  "Operations" section (`navSections`), alongside the existing `/zones`
  and `/reservations` links. `/reservations` is already in the sidebar
  today (just currently dead — it's live once module 7 lands). Consider
  swapping the `/zones` link's icon so `/tables` and `/zones` are visually
  distinct (both currently would use `Armchair`).
- `apps/restaurant-ui/src/routeTree.gen.ts`: **do not hand-edit** — this
  is generated by the TanStack Router plugin. Once the route files from
  module 5 (`routes/tables.tsx`) and module 6
  (`routes/zones.$zoneId.tsx`, replacing
  `routes/zones.$zoneId.seats.tsx`) exist, starting the dev server (or
  running the router codegen step in the build) regenerates this file
  automatically.

## Verification

- Start the dev server, confirm `/tables`, `/zones`, `/zones/:id`, and
  `/reservations` all appear in the regenerated `routeTree.gen.ts` and are
  reachable from the sidebar.
- Click through the sidebar in a browser: Operations section shows
  Tables, Zones & Seating, Reservations, each loading its respective page
  with no console errors.
